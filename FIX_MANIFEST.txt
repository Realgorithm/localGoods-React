Fix for: Netlify build error
"Module not found: Error: Can't resolve './App' in '/opt/build/repo/src'"

CAUSE: package.json had "type": "module" at the repo root. That field is
shared by both your frontend (Create React App) and backend in this repo,
and it made Webpack require explicit file extensions on every import —
breaking `import App from './App'` in src/index.js.

FIX: Decouple the backend's module system using .mjs files instead of the
package.json "type" field, so the frontend build is unaffected.

STEPS ON GITHUB:
1. Delete these 4 files:
   server/index.js
   server/db.js
   server/utils.js
   server/schema.js

2. Add these 4 files from this zip (same content, new names/paths):
   server/index.mjs
   server/db.mjs
   server/utils.mjs
   server/schema.mjs

3. Replace package.json and README.md with the versions in this zip.
